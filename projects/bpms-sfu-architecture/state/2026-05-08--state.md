## Load-bearing technical facts

### SFU ownership boundary

**Owns:** OBG ingest, lane alignment, bins selection, filter-bank synth/analysis, band gain, band Doppler, RF interfacing, timing, mgmt, debug.
**Does NOT own:** beam gain, beam Doppler, beam delay (DCU). Authoritative table: `arch/fad/FAD.md` §1.2.

### PS software scope

PL RTL only. PS hosts: TLE/SGP4 propagation, mgmt protocol stack (REST/SNMP per OI-S07), Ethernet GEM driver, NMS provisioning. PL `mgmt_if` and `band_doppler` are PL components with PS↔PL interfaces. PS counterparts in separate repo (TBD). ADR-0003 triggered at FAD §11 authoring.

### MS / uArch split (ADR-0005, pending Gastón)

- **Architect** delivers MS (`arch/modules/<module>.md`): black-box external contract. Gate G4a (`design_ready`).
- **Designer** delivers uArch (`rtl/<module>/uarch.md`): internal implementation. Gate G4b.
- Granularity: 23 MS files covering ~28 RTL instances.

### Module inventory (23 MSs, FAD §6.1)

DL/UL identical-contract → one parameterised MS, two RTL instances: `bins_sel`, `band_gain`, `band_doppler`, `band_rms_det`. `obg_link` = single bidirectional MS (one full-duplex Aurora IP). `filter_bank_synth` and `filter_bank_analysis` = two separate MSs, each wrapping a CPBF FFT4096 block per ADR-0006. `cdc_fifo_*` and `sfu_top` dropped.

### Sub-band structure

Two parallel chains per direction (Sub-band A + B), 1,024 / 1,048.576 MHz native (ASIC / FPGA-sat) / ~819.2 MHz usable each. Independent FB + band_gain + band_doppler per chain. 48 beam slots/sub-band × 2 = 96 per SFU. RF BW limit (1,600 ÷ BW) binding at ≥5 MHz.

### Clocking / reset architecture (FAD §4 v0.6.1)

- **4 clock domains:** `clk_aurora_user` (invariant) / `clk_dsp` (sat-type-scaled, 341.333333 / 349.525333 MHz exact) / `clk_rfdc_axis` (sat-type-scaled) / `clk_mgmt` (PS pl_clk0 `[ASSUMPTION: expiry ADR-0003]`).
- **Off-FPGA chain:** OBG-recovered → Si5394 (jitter cleaner, 48 MHz XAB holdover) → LMK04821 (PLL, VCXO holdover) → LMX2594 ×2 (RF PLLs) → RFdc tile PLL → `clk_rfdc_axis`. Si5394 O0/O1 → MGT TX refclks (Aurora TX) — sample-rate-invariant.
- **Solution B canonical** (`[ASSUMPTION: SFU-001 §11.1 literal; expiry OQ-§4-10, Shlomi]`). Solution A (OCXO master, OBG slow discipline) is alternative tuning point on same hardware. ADR-0002 will capture final choice.
- `clk_dsp` ↔ `clk_rfdc_axis` synchronous-derived 1:3 via MMCM — `[ASSUMPTION: FAD-DEC-17 proposed; expiry ADR-0002 + OQ-§4-3]`. No async FIFO between rfdc_wrap and DSP domain.
- Only async data crossing: OBG ↔ DSP in `obg_link` CDC FIFO.
- **Reset philosophy: control-path-only (FAD-DEC-16, hard rules R1–R6).** DSP datapath pipeline registers NOT reset. 4 resets: `rst_mgmt_n`, `rst_dsp_ctrl_n`, `rst_aurora_n`, `rst_rfdc_n`.
- NCO phase apply semantics (1PPS commit, phase coherence on reload) are MS scope — `band_doppler`, `cw_beacon` contracts, not §4. Clarified in v0.6.1 (reviewer item 3).
- `obg_link` FIFO: FAD specifies empty-state requirement at end of sample-rate switch; pointer mechanics are uArch. Clarified in v0.6.1 (reviewer item 4).
- CDC-08: Band Doppler NCO update is shadow-active atomic at 1PPS edge across all 4 NCO instances (DL/UL × A/B). Same pattern as `utc_apply_engine`. Refined in v0.6.1 (reviewer item 7).
- CDC-03/04: Aurora status/control use per-bit two-flop with explicit quasi-static contract. Annotated in v0.6.1 (reviewer item 6).
- 1PPS treated as asynchronous edge event, not a timing clock — no `create_clock` in XDC, only `set_false_path`. Fixed in v0.6.1 (reviewer item 5).
- Aurora link behaviour on discipline-source switchover (primary↔secondary) marked TBD pending OQ-§4-4 sub-q 4 (Si5394 holdover MGT-TX validity). v0.6.1 (reviewer item 2).
- **Phase coherence between G-SFU SFUs:** frequency coherence inherent (common OBG source); phase coherence NOT inherent — per-SFU phase-trim register required (OI-S02/SYS-CLK-09).
- ps_axi collapses into `mgmt` — pl_clk0 drives both (FAD-DEC-11 `[ASSUMPTION: expiry ADR-0003]`).

### Other key structural decisions

- `rf_port_sel` = digital PL-fabric mux between band-level DSP and `rfdc_wrap` (FAD-DEC-08).
- `band_rms_det` = passive tap: DL post-`band_gain_dl`; UL post-`band_doppler_ul` / pre-`band_gain_ul` (FAD-DEC-09).
- `.drawio` is single editable source for §2 diagrams (FAD-DEC-02); same policy applied to §4 clock-tree diagrams.
- CDC ownership: FAD §4.5 owns project-wide policy; mechanism in `obg_link` MS; FIFO sizing in uArch (FAD-DEC-07).
- UTC-scheduled vs Local Autonomous: `utc_apply_engine` handles shadow→live commits; `tle_compute` writes directly to `band_doppler` live NCO at 1PPS, bypassing the engine.
- `bins_sel` routing-table sharing DL/UL: `[ASSUMPTION: shared]` — confirm with Shlomi.
