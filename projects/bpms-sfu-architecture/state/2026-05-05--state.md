## Load-bearing technical facts

### SFU ownership

**Owns:** OBG ingest, lane alignment, bins selection, filter-bank synth/analysis, band gain,
band Doppler, RF interfacing, timing, management, debug.
**Does NOT own:** beam gain, beam Doppler, beam delay — those belong to DCU. Flag any
boundary-crossing proposal immediately. Authoritative table: `arch/fad/FAD.md` §1.2.

### PS software scope boundary

Repo covers PL RTL only. PS software out of scope: TLE/SGP4 propagation, mgmt protocol
stack (REST/SNMP per OI-S07), Ethernet GEM driver, NMS provisioning. PL blocks `mgmt`
and `band_doppler` are PL components with defined PS↔PL interfaces; PS counterparts live
in a separate repo (TBD). ADR-0003 triggered at FAD §11 authoring.

### Module Spec / Micro-Architecture split (ADR-0005, pending Gastón)

- **Architect** delivers MS (`arch/modules/<module>.md`): black-box external contract.
  Gate: G4a (`design_ready`). Content: ports, interfaces, clock domains, registers,
  operation, performance, errors, test hooks, system constraints, refmodel pointer.
- **Designer** delivers uArch (`rtl/<module>/uarch.md`): internal implementation
  (FSMs, pipeline, FIFOs, .sv decomposition). Gate: G4b.
- Granularity: 23 MS files covering ~28 RTL instances.

### Module inventory — 23 MS files, ~28 RTL instances (consolidated 2026-05-01)

- DL/UL identical contract → one parameterized MS with `DIRECTION` param, two instances.
- `obg_rx` + `obg_tx` → `obg_link` (single bidirectional MS; 4 Aurora lanes, full-duplex).
- `bins_sel`, `band_gain`, `band_doppler`, `band_rms_det` → each one MS, two instances.
- `filter_bank_synth` / `filter_bank_analysis` → two separate MSs (different vendor IP cores).
- `cdc_fifo_*` → **dropped**; CDC mechanism in `obg_link` MS, FIFO sizing in uArch.
- `sfu_top` → **dropped**; top integration = FAD + constraints. `uarch.md` ownership TBD (Marco).

### Key structural decisions

- **rf_port_sel (FAD-DEC-08):** digital PL-fabric mux between `band_doppler` and
  `rfdc_wrap` — NOT an analog switch. Corrected 2026-05-01; was wrongly placed post-`rfdc_wrap`.
- **band_rms_det (FAD-DEC-09):** passive tap. DL: post-`band_gain_dl`. UL: post-`band_doppler_ul` /
  pre-`band_gain_ul`. Dashed arrow in diagrams; no output back into signal chain.
- **Diagram format (FAD-DEC-02):** `.drawio` is single editable source of truth; SVGs are
  rendered exports. Three views: §2.1 top-level datapath, §2.2 sub-band detail, §2.3
  infrastructure. Mermaid retired from §2.1/§2.2; §2.3 retirement deferred (FAD-OQ-05).
- **CDC ownership (FAD-DEC-07):** mechanism policy in `obg_link` MS; FIFO sizing in uArch.
- **UTC-apply vs Local Autonomous:** `utc_apply_engine` handles shadow→live commits.
  `tle_compute` writes **directly** to `band_doppler` live NCO at 1PPS — bypasses engine.
  ADR-0004 must trigger before the first UTC-scheduled-parameter MS is authored.
- **bins_sel routing table:** `[ASSUMPTION: shared between DL/UL for same AxC]` — confirm with Shlomi.
- **"384/288" annotation** in SFU-001 Fig 5.1: `[TBD: confirm with Shlomi]`.

### Sub-band architecture and beam capacity

Two parallel chains per direction (Sub-band A + B), 1,024 MHz native / ~819.2 MHz usable
each. Independent filter bank + `band_gain` + `band_doppler` per chain. Beam slots: 48 per
sub-band (16/lane × 3 lanes), 96 total per SFU. RF BW limit (1,600 MHz ÷ BW) binding at
≥5 MHz. One MS per function; §2.2 diagram shows hardware parallelism via parallel lanes.
